# AXIOM

**Readable scientific programming for computational neuroscience.**

AXIOM is an experimental, Python-powered programming language designed to make neural models, scientific experiments, and computational research easier to express, understand, and validate.

### Our goals

- **Readable by design:** scientific code that is understandable at a glance.
- **Reproducible experiments:** explicit parameters and traceable outputs.
- **Scientific rigor:** numerical validation and clearly stated model assumptions.
- **Python-powered:** built on the scientific Python ecosystem.

### Development status

AXIOM is in its early development stage. Features will be documented as they are implemented and tested.

Our first milestone is a working interpreter and a validated, minimal neuron simulation.
